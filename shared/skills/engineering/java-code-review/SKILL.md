# Java Code Review

## When to use

Use this skill when:

- reviewing Java code
- reviewing Spring Boot code
- reviewing Pull Requests
- analyzing code quality
- checking architectural issues

## Review dimensions

1. Correctness
2. Readability
3. Maintainability
4. Performance
5. Concurrency
6. Security
7. Database access
8. Spring best practices
9. API design
10. Test coverage

## Process

### Step 1

Understand the purpose of the change.

### Step 2

Identify correctness problems.

### Step 3

Check architecture and maintainability.

### Step 4

Check security and performance.

### Step 5

Return findings using:

Critical
High
Medium
Low
Suggestion
